# Вердикт по находке

## Обзор

Находку опровергает только код, из которого следует обратное её утверждению.
Нет такого кода — находка устояла.

## Что опровергает

Вот вызов, вот условие выше, вот проверка в предке.

Находка, которая противоречит сама себе или просит автора что-то проверить
вместо утверждения, опровергается: содержания в ней нет.

## Вес

Считай по шкале, на которой находка написана: поведение — по последствию для
данных и пользователя, качество — по цене будущей правки.

## Частые ошибки

- «Это придирка», «код работает», «читаемость не повод» — мандат находки ты не
  судишь, это не опровержения.
- «Ничего не ломается» — вес качественной находки этим не снижается.
